# Prompt pour Génération de Logo - ChezLibrairie

## Prompt Principal (pour DALL-E, Midjourney, Stable Diffusion)

```
Professional modern logo design for "ChezLibrairie", a French online bookstore. The logo features an elegant book icon integrated with the letter "C" or stylized books forming the letter "C". Design style: minimalist, contemporary, premium. Color palette: vibrant blue (#2563eb) transitioning to lime green (#84cc16) with golden yellow accents (#facc15). The logo should incorporate subtle gradient effects and glassmorphism elements. Clean, scalable vector-style design suitable for both light and dark backgrounds. Typography: modern sans-serif font (Poppins-inspired), bold and readable. The design should convey sophistication, knowledge, and digital modernity. White background, centered composition, professional logo presentation, high resolution, 4K quality.
```

## Prompt Alternatif (Style Plus Détaillé)

```
Create a premium logo for "ChezLibrairie" online bookstore: elegant minimalist design combining an open book or stacked books with a stylized letter "C". Modern geometric shapes, smooth curves, professional vector illustration. Color scheme: deep blue (#2563eb) to bright lime green (#84cc16) gradient with golden yellow (#facc15) highlights. Glassmorphism effect with subtle transparency and blur. Clean, modern typography in bold sans-serif. The logo should work on both light and dark backgrounds. Style: contemporary, sophisticated, digital-first, premium brand identity. Isolated on white background, centered, high quality, professional logo design, 4K resolution.
```

## Prompt pour Style Classique/Élégant

```
Elegant French bookstore logo "ChezLibrairie": classic book illustration merged with modern typography. Design elements: open book with pages, quill pen, or library symbol integrated into letter "C". Sophisticated color palette: royal blue (#2563eb), fresh green (#84cc16), and warm gold (#facc15) in gradient form. Modern minimalist approach with refined details. Professional vector logo style, scalable, clean lines. Typography: bold, elegant sans-serif font. Conveys tradition, knowledge, and contemporary digital presence. White background, centered, high-resolution logo design.
```

## Spécifications Techniques

### Couleurs Principales
- **Primary (Bleu)**: #2563eb
- **Secondary (Vert Lime)**: #84cc16  
- **Accent (Jaune Or)**: #facc15
- **Texte**: #1f2937 (gris foncé)

### Style Visuel
- Design moderne et minimaliste
- Effets de gradient fluides
- Éléments glassmorphism subtils
- Formes géométriques élégantes
- Adaptable clair/sombre

### Éléments à Intégrer
- Livre(s) ouvert(s) ou empilé(s)
- Lettre "C" stylisée
- Typographie moderne (style Poppins)
- Éléments graphiques subtils (pages, lignes de texte, etc.)

### Format Recommandé
- Format: SVG ou PNG haute résolution (minimum 2000x2000px)
- Fond: Transparent ou blanc
- Versions: Logo complet + icône seule (favicon)

## Instructions d'Utilisation

1. **Pour DALL-E 3** : Utilisez le prompt principal tel quel
2. **Pour Midjourney** : Ajoutez `--style raw --v 6` à la fin du prompt
3. **Pour Stable Diffusion** : Utilisez le prompt avec des poids négatifs pour éviter les éléments indésirables

## Variantes à Demander

- Version horizontale (logo + texte côte à côte)
- Version verticale (icône au-dessus du texte)
- Version icône seule (pour favicon)
- Version monochrome (pour impressions)
- Version avec fond sombre
